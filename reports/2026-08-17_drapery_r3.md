## FOUND

Five issues from founder review (2026-08-17):

1. **Elevation closed, panels stack CLOSED** — the R2 default elevation
   was one big fabric rect (panels stacked CLOSED). Founder: "the fatal
   flaw" — drapery must be GATHERED by default, panels stacked back,
   window/glass visible between stacks.
2. **DETAIL A read as HARDWARE** — the side-section profile (D-R2-1
   magnified view) looked like a metal bracket. Founder: redesign as
   PLAN-VIEW pleat detail (looking down on the rod).
3. **Heading styles incomplete** — only pinch_pleat + ripplefold had
   drape-projection constants; grommet and rod_pocket were absent.
4. **Fabric model missing orientation** — no field for "STANDARD" vs
   "RAILROADED"; railroaded fabric needs different repeat-direction
   rendering and a title-column note.
5. **Gate blind spot** — the `DIMENSIONS:` label (letterspaced, with
   tracking 1.5) extended into the value-column x range, but
   `text-collision` gate PASSED. Root cause: pdfplumber merged
   `DIMENSIONS:` + `87.00" W × 84.00" H` into ONE word
   `DIMENSION8S7.0:0""`, hiding the overlap from word-level checks.

### `backend/app/services/drawing/templates/b2_qc.py`
- **D-R3-5 gate fix**: `_check_text_collision` adds a merged-word
  detection pass. If a single pdfplumber "word" is wider than
  1.40" AND contains a digit AND has > 18 chars, internal
  char-overlap is flagged. Catches the case where label
  letterspacing merges the label + value into one pdfplumber
  word, hiding the overlap from the original word-level check.
- **D-R3-5 layout fix**: title column `_render_title_column`
  computes the value-column x offset dynamically from the
  longest tracked label (was hardcoded 0.70" → too narrow for
  tracking=1.5 on `DIMENSIONS:` at 0.86" wide). Uses
  ReportLab's `stringWidth` to measure each label precisely.
- Shortened NOTES / ASSUMPTIONS rows so they fit within the
  title column (no overflow past x=10.5). Was overflowing by
  ~0.04" after the value-column widening.
- **D-R3-1 gate**: new `_check_gathered_elevation` gate. Pixel
  scan on front elevation viewport at 150 DPI:
    (a) Central 20% of viewport must NOT be fabric-colored
        (glass visible). Detection by HSV saturation proxy
        (max-min > 30), so returns (brown, low sat) and bg
        cream aren't confused with fabric.
    (b) Each side stack width within ±20% of
        `STACK_WIDTH_PER_PANEL_IN` (single panel fabric
        width gathered, regardless of how many panels nest).
  Negative fixture: closed-panels render must FAIL.
