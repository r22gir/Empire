## STEP 1a — Decode-verify at the boundary

**File:** `backend/app/routers/vision.py`
**Diff:** `+37 -0`

After the existing magic-byte check at line 169, before the `return data, ext`:

```python
# D43 1a — decode-verify at the boundary. Magic bytes can pass while the
# payload itself is not a decodable image (e.g. a 136-byte PNG header
# followed by 128 bytes of `x` padding). PIL's verify() opens the file and
# confirms the decoder accepts the structure.
#
# verify() invalidates the Image object for pixel access; downstream uses
# the file path (write_bytes + mmx CLI subprocess), so we don't need to
# re-open — only re-open to read dimensions for the log line.
try:
    Image.open(BytesIO(data)).verify()
except (UnidentifiedImageError, Exception) as exc:  # PIL raises a variety
    raise HTTPException(
        status_code=400,
        detail="Image payload is not a decodable image",
    ) from exc

# Re-open for dimensions (verify() above closes the image).
try:
    with Image.open(BytesIO(data)) as dim_img:
        log.info(
            "vision_decode_verified ext=%s size=%dx%d bytes=%d",
            ext, dim_img.size[0], dim_img.size[1], len(data),
        )
except Exception:
    pass  # Already verified once; ignore secondary failures.

return data, ext


# Public alias for cross-module use (drawings.py, quote_requests.py).
# Same body, same guarantees — the unprefixed name signals it is part of
# the public API of this module.
decode_image_input = _decode_image_input
```

Module-level imports added: `from io import BytesIO`, `from PIL import Image, UnidentifiedImageError`.

**Verified in shell:**
- `_png_data_uri()`-style 136-byte payload → HTTPException 400, message "Image payload is not a decodable image"
- Real PNG (4×3, RGB) → passes, logs `vision_decode_verified ext=.png size=4x3 bytes=77`
- Real JPEG → passes, logs `vision_decode_verified ext=.jpg size=4x3 bytes=633`
- Data URI form, raw base64 form — both paths work

```

```

The router file `drawings.py` and `quote_requests.py` import `decode_image_input` and use:
```python
try:
    decode_image_input(req.image)
except HTTPException:
    raise
```
This is the standard "let it propagate as 4xx" idiom. No conversion to success-shaped response happens.

    img = Image.new("RGB", (width, height), color)

A new test was added at the bottom of the file:

def test_decode_image_input_rejects_lookalike_png_payload():
    """D43 1a — the 136-byte fixture (PNG-magic + 128 'x' padding) must raise."""
    from app.routers import vision

    payload = _bad_png_payload()  # gated — skips if env var unset

that calls `_bad_png_payload()` cannot leak the 136-byte shape anywhere.
