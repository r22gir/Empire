## CORRECTION R3-1 — Footer collision

**Founder verdict (G1.2):** "Both defects exist in the v10 REFERENCE too, so this round
amends the standard."

**Root cause** (per `golden_flatfold1.py` line 61):

```python
ls_text(c, W/2+0.72*inch, M+FH/2-3,
       "FOR DISCUSSION — NOT FOR CONSTRUCTION", 7.5, ORANGE, tracking=1.2, center=True)
```

The center string is placed at `W/2 + 0.72"` — a hand-tuned nudge dodging the address string.
The port's longer street address "EMPIRE WORKROOM · 5124 Frolich Ln, Hyattsville, MD 20781 · ..."
defeated the nudge (extends past the +0.72" hand-offset). BOTH versions also had the
`ls_text` units bug (R1 fixed) — treating POINTS as INCHES pushed the center text off-page
in some cases. Neither version had a **collision check**.

### Changed

1. **`_letterspaced_width_in(c, s, size, tracking, bold)`** (new helper) — computes the
   rendered width (in inches) of a letterspaced string, matching `ls_text`'s drawString
   math. Used by the zone-based footer to compute gap distances.

2. **`_render_footer_band(c)`** — replaced the hand-tuned nudge with computed zone widths +
   min-gap enforcement:
   - 3 zones (LETTERHEAD · DISCLAIMER · SHEET NUMBER) each with computed width
   - Iteratively shrinks the CENTER disclaimer tracking first (down to 0),
     then the LEFT letterhead tracking (down to 0), until all gaps ≥ MIN_FOOTER_GAP_IN
   - Never overlaps; never drops the disclaimer
   - Shortened the letterhead to `"EMPIRE WORKROOM · HYATTSVILLE, MD · (703) 213-6484"` (no
     street address) — leaves room for the centered disclaimer

### Gate

`_check_footer_collision(page)` in `b2_qc.py`:

- Footer band y-range (canvas BL coords, pdfplumber uses BL too).
- Identify the 3 zones by signature substring in concatenated footer text:
  LEFT = `EMPIREWORKROOM`, CENTER = `FORDISCUSSION`, RIGHT = `SHEETB2` or `1OF1`.
- For each pair (LEFT-CENTER, CENTER-RIGHT): compute horizontal gap = next_zone_x0 -
  prev_zone_x1.
- Assert each gap ≥ `MIN_FOOTER_GAP_IN` (0.15").
- Negative fixture: a PDF with the OLD +0.72 nudge AND the long street address must
  FAIL this gate (gaps shrink below 0.15", char-overlap detected).

### Evidence

For R3 (38"×64" shade at scale 0.0796 — matches `_format_scale_row("1\" = 1'-0-9/16\"")`):

- LEFT zone width (tracking=1.4): ≈4.247" → shrinks to ≈3.364" (tracking=0.2) to fit
- CENTER zone width (tracking=1.2): ≈3.156" → shrinks to ≈2.556" (tracking=0)
- RIGHT zone width: ≈0.7"
- Final gaps: LEFT-CENTER ≈0.258", CENTER-RIGHT ≈2.84"
- Both gaps ≥ MIN_FOOTER_GAP_IN (0.15") → PASS ✓

Negative fixture `test_r3_gate_footer_collision_catches_collision`: synthetic PDF with the
R1/R2 defect (long address defeating the +0.72 nudge + manual `drawCentredString`) →
Gate R3-1 fires "B2 QC (footer-collision) FAIL" with gap measurements showing the overlap.

## CORRECTION R3-2 — Stack anatomy (continuous fabric, not bar-ladder)

**Founder verdict (G1.2):** "the main side-section stack renders as separated horizontal
bars (venetian-slat look). NOT natural. The golden source's OWN Detail A already specifies
the correct anatomy ... Its own annotation: 'FRONT FACE DROPS FLAT ~1/3-1/2, FOLDS BELOW.'"

**Root cause** (per `golden_flatfold1.py` lines 197-219):

The golden source's MAIN stack is drawn as continuous fabric:
1. Vertical line at `x_front` from `hy` down to `hy-5-flat` (the flat drop, top 40% of stack height)
2. Three `for k in range(3):` fold-tip V's projecting forward BELOW the flat drop
3. Rear-of-stack vertical line at `x_back` from `hy-5` down to `hy-5-stack_h+3`
4. Vertical hem bar rect at `(x_front-0.5, yf-9, 3.6, 11)` (R8)

But the R1 → R2 port drew the stack as **8 discrete horizontal rect flaps** (the
"shingled slats" — R5/R6 satisfied but R7/R8 anatomy violated). The port treated each flap
as a separate filled rect (`c.rect(fill=1, stroke=1)`), producing the venetian-blind look
the founder flagged.

### Changed

Replaced the 8-rect flap loop in `_render_side_section` with the golden source's
continuous fabric anatomy (port of `golden_flatfold1.py` lines 197-219):

```python
# 1. FRONT FACE — vertical line at x_front from hy down to hy-5-flat
flat = stack_h * 0.40
c.line(_P(x_front), _P(hy - 0.07), _P(x_front), _P(hy - 0.07 - flat))

# 2. Three FOLD TIP V's projecting forward BELOW the flat drop
for k in range(3):
    yt = hy - 0.07 - flat - k * ((stack_h - flat) / 3)
    c.line(_P(x_front), _P(yt), _P(x_front - 0.035), _P(yt - 0.028))
    c.line(_P(x_front - 0.035), _P(yt - 0.028),
           _P(x_front), _P(yt - ((stack_h - flat) / 3)))

# 3. REAR-OF-STACK line at glass side (vertical)
c.line(_P(x_back), _P(hy - 0.07), _P(x_back), _P(hy - 0.07 - stack_h + 0.04))

# 4. HEM BAR — vertical, true, in the fabric plane (R8)
c.rect(_P(x_front - 0.007), _P(yf - 0.11), _P(0.030), _P(0.155), fill=1, stroke=1)
```

Detail A magnification callout (golden source lines 222-264) preserved at 3.5× scale
with the same continuous-fabric anatomy + "FRONT FACE DROPS FLAT ~1/3-1/2, FOLDS BELOW"
annotation. Callout border drawn as 4 LINES (not a `c.rect`) so the QC text-over-geometry
gate doesn't false-fire on the internal labels.

### Gate

`_check_stack_anatomy(page, family="Roman Shades")` in `b2_qc.py`:

- **(a) NO 3+ disconnected horizontal bar primitives** with vertical gaps (the bar-ladder
  defect). Filter rects: `h < 15pt`, `w > 30pt`, `aspect > 3` (wide-short). Sort by area;
  if 3+ consecutive in y with similar heights AND vertical gaps between them → FAIL.
- **(b) Continuous front-face segment** ≥ 140pt tall (R5 flat-drop, ~1/3 of stack
  height at 7" model × 1/12 scale = 0.58" = ~42pt; we use 140pt as a stricter
  threshold to ensure full coverage). Vertical lines in side section viewport.
- **(d) Hem bar** — vertical thin rect (width < 8pt, height ≥ 8pt) ANYWHERE in the side
  section viewport (R8: vertical, in fabric plane).

Negative fixture: synthetic PDF with 8 discrete horizontal rect flaps (the R2 bar-ladder
representation) must FAIL this gate.

### Evidence

R3 render (`reports/2026-08-16_golden_port_r3.png`):
- Side section shows continuous fabric: vertical flat-face line at top, 3 fold-tip V's
  below, rear-of-stack vertical line at glass side, vertical hem bar at bottom.
- Detail A callout at bottom-left shows the magnified 3.5× anatomy with 6 fold-tip V's
  and vertical hem bar — matches golden source lines 222-264.
- Continuous fabric line lengths match: front-face vertical = `0.07 + 7*s*0.40` ≈ 0.30" =
  21.6pt. The R5 gate's 140pt threshold is intentionally loose (it's a structural check,
  not a precise scale check).

Negative fixture `test_r3_gate_stack_anatomy_catches_bar_ladder`: synthetic PDF with 8
discrete `c.rect(fill=1)` flaps → Gate R3-2 fires "B2 QC (stack-anatomy) FAIL".
