### 3.2 The trivial task

The prompt asked for a `shell_execute` of `echo 'r9-evidence-marker-…' >>
/tmp/codetask_r9_evidence.txt`. This was deliberate but suboptimal — the
validator at `code_task_runner.py:889-897` only tracks file changes from
`file_write`/`file_edit`/`file_append` tools. `shell_execute` bypasses the
tracker even though the file IS written. A `file_append`-based prompt would
have succeeded. This is a SEPARATE validator defect, not on R9's scope.
